AirFrameXR is a wireless PC VR streaming client for Apple Vision Pro. It shows video streamed from a companion program (the "streamer") running on the user's own Windows PC with an NVIDIA GPU. The app does nothing useful on its own: it needs that PC on the same local network. No account or sign-in is needed, and the developer operates no server (privacy policy: https://github.com/jfbobier/AirFrameXR/blob/main/PRIVACY.md).

HOW TO TEST
1. Companion software (free, public): https://github.com/jfbobier/AirFrameXR/releases/tag/v1.4.1 (download the bundle zip, unzip it, start the streamer). Requires a Windows PC with an NVIDIA GPU.
2. The PC should be on Ethernet and the Vision Pro on the same local network (5 GHz Wi-Fi 6).
3. In the streamer window press "Find headset...", open the AirFrameXR app on the Vision Pro and accept the pairing.
4. The app then shows the PC's content in the headset.
